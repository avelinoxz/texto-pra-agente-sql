# texto pra sql

Um agente de IA open-source que converte linguagem natural em SQL. Faça perguntas sobre seus dados em linguagem simples — o agente gera, executa e explica consultas SQL utilizando os recursos de raciocínio avançado do Claude.

Sera Desenvolvido com **LangGraph + FastAPI + Next.js**. Suporta **PostgreSQL, MySQL e upload de arquivos CSV**.
